Parameter & Konfigurasi Sistem

Pengaturan identitas Posyandu, API notifikasi gateway, standar WHO antropometri, dan keamanan JWT/Sesi
1. Pengaturan Unit Posyandu (SRS Batasan 2.4)
Versi MVP difokuskan melayani 1 unit Posyandu sebelum diperluas ke multi-Posyandu (SCAL-001).
2. Gateway Notifikasi Otomatis (WhatsApp & Web Push)
Konfigurasi token API untuk pengiriman pengingat jadwal H-3, H-1, dan hari-H pukul 07.00 WIB.
3. Ambang Validasi Antropometri (Permenkes No. 2/2020)
Batas nilai wajar input pengukuran kader untuk mencegah salah ketik angka (KADER-009).
4. Keamanan Sesi & Perlindungan Akun
Aturan otomatis auto-logout dan penguncian akun dari percobaan login berulang.
